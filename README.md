1. Sistema de Gerenciamento de Notas
Funcionalidades
• cadastrar notas; 
• calcular média; 
• verificar situação do aluno; 
• validar notas inválidas. 
Regras
• média ≥ 7 → aprovado; 
• média entre 5 e 6.9 → recuperação; 
• média < 5 → reprovado. 
Sugestões de Testes
• média correta; 
• nota inválida; 
• aprovação correta.
